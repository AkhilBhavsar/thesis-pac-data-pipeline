# Project Budget

Creates a monthly AWS cost budget scoped to the MSc thesis project.

## Scope

- Project = thesis-pac
- Environment = dev
- Metric = UnblendedCost
- Monthly limit = USD 2.00

## Notifications

- Actual spend greater than USD 0.10
- Actual spend greater than 50%
- Actual spend greater than 80%
- Actual spend greater than 100%
- Forecasted spend greater than 100%

Existing account-wide budgets remain unchanged as additional safeguards.
